# L9–L11 · 奖励、数据筛选与训练代价

这些来源帮助判断何时该修评价，何时值得改数据、目标函数或系统。优先用固定轨迹和简单对照检查。没有对目标 Infra 行为训练新模型。

### `arxiv:2308.08998`

- 原文：[Reinforced Self-Training v2](https://arxiv.org/html/2308.08998v2)
- 范围：§3 的 Grow/Improve、§4 的翻译对照与数据过滤，附录 B 的阈值设定。
- 方法与限制：从当前策略收集样本，按奖励过滤，再用离线方法改进策略。一次采样可复用多轮，降低重新生成的成本。翻译实验用偏好模型或指标近似质量，分数可能提高但人工质量下降。
- 工程用法：先从现有实验筛少量示范，逐条核对是否确实采取了合适的下一步。对筛选分数高的样本做独立复核，再测原始模型与示范输入。若通过样本只集中在短任务，按工作家族补代表性证据。

### `arxiv:2312.06585`

- 原文：[Beyond Human Data · ReST-EM v4](https://arxiv.org/html/2312.06585v4)
- 范围：§4 的 Generate/Improve、§5 的数学和代码对照及迁移，Fig. 7。
- 方法与限制：用规则奖励留下成功解，从基座做训练。作者的任务上，反复从同一基座训练相对续训能获得更好跨任务迁移。给正确答案后再生成解释的初步试验产生了更多「答案对、理由错」。
- 工程用法：不能把事后已知的好策略当作模型从当时证据自主作出的示范。记录决策时可访问的输入，分别保留真实决策和事后专家分析。若候选有高成功率但路径不可重现，先补过程验收。

### `arxiv:2402.03300`

- 原文：[DeepSeekMath v3](https://arxiv.org/html/2402.03300v3)
- 范围：§4.1.1–4.1.4、§4.2、§5.2 与 Appendix A.1.6 的 GRPO。
- 方法与限制：用同一题多个答案的相对奖励构造 advantage，省去独立 critic，结合 ratio/clipping 和参考策略正则。结果监督和过程监督用不同的赋分。论文同时有预训练和 SFT 变化。
- 工程用法：核对 A3 的组内均值、std、KL、有效 token 和梯度分母。先给同题全对、全错、混合组的离线 fixture，记录实际更新和掉组原因。如果全错来自验收错标，先修 verifier。只有组内确实有可区分的行为才解释训练信号。

### `arxiv:2503.20783`

- 原文：[Understanding R1-Zero-Like Training · Dr. GRPO v2](https://arxiv.org/html/2503.20783v2)
- 范围：§§3.1–3.2、Table 2、附录 Fig. 8 的长度与 std 消融。本次为 v2，原 A3 技术专题用 v1 的对应段落。
- 方法与限制：按生成长度归一会改变长短输出的 token 权重，组内 std 归一也改变题间权重。不同实现含隐式选择。论文重分解损失以减少其分析的偏差，A3 的简化实现有自己的 batch 分母。
- 工程用法：若训练后 Infra 轨迹变长，先按正确性和结果分类，观察长错误和短正确的权重。对同一固定数据分别计算序列与 token 归一，再看验证集的下一步决策。不要把更长输出视作工作质量提高。

### `arxiv:1506.02438`

- 原文：[Generalized Advantage Estimation v6](https://arxiv.org/html/1506.02438v6)
- 范围：§§2–4 的折扣、TD residual 与 bias–variance，§6 的连续控制实验和 §7 讨论。
- 方法与限制：用指数加权的 TD residual 估 advantage，调节长程信用和估计方差。折扣与 λ 作用不同，价值模型不准时会带来偏差。原实验是连续控制。
- 工程用法：若事后结果不足以指出错误发生在哪步，可先用人工和外部状态给少量关键动作打标签。能稳定定位错误后再考虑学 critic。若价值估计无法跨硬件和任务泛化，保留可检验的运行步骤和最终验收。

### `arxiv:1707.06347`

- 原文：[Proximal Policy Optimization Algorithms v2 PDF](https://arxiv.org/pdf/1707.06347v2)
- 范围：§§2–5 的 surrogate、clipped 和 KL 形式、采样更新，§6 的原任务实验。
- 方法与限制：比较新旧策略对同动作的概率比，用 min 与 clip 限制继续有利方向更新的激励。clip 只是目标函数的一部分，不能保证每个 ratio 或实际 KL 都在某个边界内。
- 工程用法：若 PPO 训练不稳，用同一批带原始 logprob 的轨迹复算正负 advantage、clip fraction、KL 与模型版本，先查 mask、顺序和后端差。比较目标或超参前先证明在同一数据上计算了期望目标。

### `arxiv:2507.18071`

- 原文：[Group Sequence Policy Optimization v2](https://arxiv.org/html/2507.18071v2)
- 范围：§§3–5 的序列归一 ratio、与 GRPO 比较、token 变体、MoE 实验和后端差异。
- 方法与限制：序列对数概率差以长度归一，再指数化做 sequence-level clipping；同序列 token 共享相应权重。论文在特定 Qwen3 MoE 配置报告更稳定。序列归一可平滑 token 差异，不能直接证明所有 token 对齐正确。
- 工程用法：同 checkpoint 对比 inference 与 trainer 的 token ID、token logprob 和序列聚合值。若局部 mismatch 来自 tokenizer、EOS、expert route 或 dtype，先修该契约。只有版本和数据正确后，才比较按 token 与按序列训练的质量和成本。

### `arxiv:2503.14476`

- 原文：[DAPO v2](https://arxiv.org/html/2503.14476v2)
- 范围：§§3.1–3.4、Algorithm 1、§4 与训练曲线，核对 dynamic sampling、token-level loss 和过长输出。
- 方法与限制：过滤没有可区分奖励的整组，补采以维持有效训练样本。裁剪上界、loss 归一和过长惩罚也变了。数学对照有规则评分。弃掉全组仍消耗采样资源。
- 工程用法：同时报生成样本、有效样本、丢弃组、长尾、GPU 时间和 held-out 质量。对 A3 先分辨全错组是模型不会、配置未生效或验证器错误，再决定过滤或补数据。测单一变化时保留其它实现不变。

### `arxiv:2605.07331`

- 原文：[Cumulative Token Policy Optimization v1](https://arxiv.org/html/2605.07331v1)
- 范围：§§2、3.1–3.3、4.1–4.4 与 Appendix A 的假设和实验。
- 方法与限制：当前位置之前的 ratio 累乘纠正到达该前缀的分布，避免无关后缀的方差。无偏性针对真实 token advantage 等理论条件。实际实现仍用代理奖励与裁剪，不能把理论条件直接当作实做性质。
- 工程用法：读异步轨迹时按 token 位置、rollout 版本和任务检查 ratio、前缀累计偏差与 clipping。若只有个别 batch 因改写模板或错 token 对齐异常，先修记录与重放。单比均值无法区分 stale 与数据错配。

### `arxiv:2305.20050`

- 原文：[Let’s Verify Step by Step v1](https://arxiv.org/html/2305.20050v1)
- 范围：§§2–4 的过程和结果标签、固定候选上的 best-of-N、Fig. 3–4，以及 §6 讨论。
- 方法与限制：过程标签指向错误步骤，结果标签便宜但不能区分碰巧答对的过程。作者的大规模 PRM/ORM 使用不同数据构造，另做较小规模对照。数学题的可标注性不能直接外推到工程根因。
- 工程用法：给「读到错版本」「计时口径错」「下一步无区分力」单独标签，同时保留最后的正确性和实际收益。若专家对步骤优劣分歧大，先用硬规则与结果验收。训练标签来自独立审阅，不用最终得分反填每一步。

### `arxiv:2506.13585`

- 原文：[MiniMax-M1 · CISPO v1](https://arxiv.org/html/2506.13585v1)
- 范围：训练方法中 CISPO 的公式与 detach、Fig. 2、实验设置与公开限制。
- 方法与限制：裁剪重要性权重再停止其梯度，使 token 的 logprob 梯度贡献仍在。论文在 Qwen2.5-32B 数学训练中比较 DAPO/GRPO，报告达到某性能约用 DAPO 一半训练步，另用动态采样与长度处罚。步数不等于 GPU-hours。
- 工程用法：若评估训练效率，固定样本、输入长度、有效 token 及硬件，分别记录步数、wall time、GPU-h 与质量。先核实际梯度权重，再比较不同裁剪。用户的目标若是减少工具错误，先检验无需训练的接口和示范。

### `arxiv:2603.08640`

- 原文：[PostTrainBench v2](https://arxiv.org/html/2603.08640v2)
- 范围：§2 的资源与评价、§§3–4 的结果和预算消融、§7 限制。聚焦评估有效性、样本隔离和资源口径。
- 方法与限制：用单 H100 与限定墙钟测试 agent 是否能做指定后训练。结果随任务不同，专门优化一个分数与通用指令模型目标不同。更高推理强度在部分设置消耗更多且没有更高分。
- 工程用法：如果最终要做训练数据，先验证行为可稳定标注，明确任务族留出和数据来源。固定工具、实验预算和质量目标，比较同模型规则、示范与训练。记录工作结果、人工返工、GPU 和 token 成本。仅基准得分不足以推出实际工程价值。
