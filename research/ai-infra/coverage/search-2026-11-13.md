| L15 p.37 · [Hodoscope v1](https://arxiv.org/html/2604.11072v1) | §3.1 的评估环境隔离结果。评估得分受仍能看到的历史资料影响。 | 用隔离快照验证两组都只能查当时存在的文件。专门测试对事后结论的访问。 |
| L15 · [LangGraph Workflows and Agents](https://docs.langchain.com/oss/python/langgraph/workflows-agents) | Workflows and agents、Evaluator-optimizer。固定图也能使用条件边和反馈重试。 | 给固定流程有意义的分支与反馈。只有剩余选择需要探索时才测开放式工具调用。 |
| L4 · [Agent Workflow Memory v1](https://arxiv.org/html/2409.07429v1) | §2.2–2.3、§3.1。把过去经验归纳成工作流，在线方式由模型判定是否成功。 | 学到的流程先保留原始证据和适用条件。配对数据可用于人工审查，避免把一次顺利退出固化为成功经验。 |
| L17 · [Humans are Missing from AI Coding Agent Research v1](https://arxiv.org/html/2608.12355v1) · [Terminal-Bench v1](https://arxiv.org/html/2601.11868v1) | 前者引言和 §2 的协作度量问题，后者附录 C.1 的任务结束与验证失败类别。 | 评分包括工程师接管、修订和主动时间，并把未达到任务目标的停止标为失败。 |
| L20 · [Teaching Large Language Models to Self-Debug v2](https://arxiv.org/html/2304.05128v2) | §3、§5.2.2。检查执行反馈与模型自评的对照。原实验在文本到 SQL、代码翻译和代码生成任务。 | 模型自评可补候选假设。有可用工具时，记录额外真实观察带来的决策增量。 |
| L20 · [Tree Search for Language Model Agents v4](https://arxiv.org/html/2407.01476v4) | §§3.3、5.4、附录 A.4.1。搜索和 reset/replay 要花成本。浏览器模拟器可以恢复更多历史状态。 | GPU 分配、训练和部署的状态有独立成本。先比较只读候选和可恢复状态，再考虑额外实际运行。 |
| L20 · [Verbalized Sampling v4](https://arxiv.org/html/2510.01171v4) | 摘要、实验 Evaluation 的语义和词汇多样性口径，未核全部结果表。 | 机制不同和文本措辞不同需要分开打分。当前案例缺新增候选的真实试验结果。 |
| L20 p.29 · [WHALE v1](https://arxiv.org/html/2609.00196v1) | 摘要、§§3–4 交替训练和 harness 搜索的设计。 | 权重和 harness 可能互相制约。先测哪个环节出错，再选择是否值得训练。作者结果来自问答、数学和棋题。 |
